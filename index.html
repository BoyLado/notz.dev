Practice Concept

AJL-Handicraft

Static HTML → OS 2.0 Custom Theme

The Challenge: Started from a static HTML design that was completely non-dynamic and required manual code changes for any update. The goal was to rebuild it as a Shopify Online Store 2.0 theme using native Liquid, without relying on third-party apps, to demonstrate clean architecture and merchant empowerment.

  • Developed a fully custom OS 2.0 theme from the ground up
  • Migrated static HTML to JSON templates
  • Optimized all images by converting PNG/JPG to WebP for faster load times
  • Eliminated third-party app dependencies—including Monster Cart, and Essential Announcement Bar—by building native Liquid replacements
  • Integrated Metafields and Metaobjects for dynamic, merchant-editable content
  • Empowered full merchant control through the Shopify Theme Editor
Shopify OS 2.0 Liquid Metafields Metaobjects Native JS
  • ✓
    100% Native Architecture — All features built with custom Liquid and metafields, eliminating the need for Monster Cart, Essential Announcement Bar, and other third-party apps.
  • ✓
    $0 Monthly App Expenses — Since no apps are used, the store has zero recurring costs, maximizing profit margins.
  • ✓
    Full Merchant Control — OS 2.0 JSON templates and drag-and-drop sections allow non-technical users to manage content easily.
