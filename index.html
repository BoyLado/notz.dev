MEA Custom Suits — Shopify Theme Modernization

The Challenge: The store was built using static Liquid templates, preventing the merchant from updating layouts and content through the Shopify Theme Editor. They also needed a custom Size Finder for tailored suit measurements and a flexible Giveaway Form for marketing campaigns, but no solution matched their workflow.
  • Migrated static theme to Shopify Online Store 2.0 with JSON templates
  • Built reusable sections with Schema settings for merchant‑friendly editing
  • Developed a custom Size Finder app tailored to suit measurements
  • Created a dynamic Giveaway Form powered by Metafields
  • Eliminated dependency on third‑party apps for core functionality
  • Made the theme scalable, maintainable, and future‑proof
